# Fine Stock Database Documentation & Migrations

This directory holds the database schema definitions, architecture diagrams, and migration scripts for Supabase PostgreSQL.

## Core Principle
> *"The ledger is truth, everything else is a view."*

All authoritative stock mutations in Fine Stock write immutable ledger entries, from which stock positions and analytics are derived.
